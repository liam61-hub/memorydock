01

Every tool remembers — separately.

// pain #1

Your agents forget each other

Claude Code learns something on Monday; by Thursday, Cursor starts from zero. Every session begins with amnesia, and every tool has its own.

// pain #2

Your memory lives in someone else's cloud

Conversations, decisions, context — they pile up in vendor silos you can't read, export, or delete on your own terms.

// pain #3

Your notes aren't agent-readable

You can write things down, but no file of notes answers a question mid-task. Agents need memory they can query.

One notebook, on your machine, spoken over MCP. That's MemoryDock.

04

Three steps to a shared memory.

Run the server

One command on your machine. It creates a local notebook under ~/.memorydock — Markdown notes plus a rebuildable search index.

Point your agents at it

A few lines of MCP config per client. The same notebook for every tool you use.

Tell it to remember

Your agent saves what matters. Later, any agent can ask and get answers.

05

Install from GitHub source.

terminal GitHub 
git clone https://github.com/liam61-hub/memorydock.git
cd memorydock/server
npm ci && npm pack
npm install -g ./memorydock-2.0.0.tgz
memorydock init
