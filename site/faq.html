FAQ

Straight answers about pricing, privacy, keys, and how MemoryDock compares to the alternatives.

Pricing

Is MemoryDock free?

Yes. MemoryDock is free and open source under Apache-2.0.

Why give it away?

Honestly: we'd rather build in public and learn what people actually need than guess behind a paywall. The project is open source under Apache-2.0 — everything released stays free.

Privacy & data

Where is my data stored?

In Markdown notes under ~/.memorydock/notes/ on your machine. The LanceDB search index is derived from those notes. MemoryDock has no cloud database or account.

Does MemoryDock send my data anywhere?

Only to your embedding provider, using your key — because embeddings have to be computed somewhere. Pick Ollama and nothing leaves your machine at all. MemoryDock itself has no accounts, no telemetry, and no analytics.

Can I delete everything?

Export anything you want to keep, uninstall the program, then delete the local data folder. MemoryDock keeps no remote copy.

Do you track this site?

No analytics, cookies, trackers, or third-party scripts.

Bring your own key

Which embedding providers work?

Any OpenAI-compatible endpoint. Verified so far: OpenAI, together.ai, and Ollama (local). If it speaks the protocol, it should work — tell us if one doesn't.

What if my model isn't 1536-dimensional?

Set EMBEDDING_DIM to whatever your model outputs. After switching models, run memorydock reembed --yes --backup to rebuild all vectors — the rebuild is atomic, so a failure leaves your data untouched. See the quickstart.

Do I need an LLM key too?

No. The LLM key is optional and used for exactly one feature: summarizing projects during import. Without it, MemoryDock falls back to a README snippet — everything else works.

Multi-agent & sharing

Can several agents share one memory?

Yes — that's the core use case. One MemoryDock server on your machine, and every MCP client (Claude Code, Codex, Cursor, or anything else) reads and writes the same notebook.

Can a teammate and I share a memory?

No — it's deliberately single-machine. There is one edition, and it stays on your computer.

Editions

Are there other editions?

No. MemoryDock ships one edition: a single-machine, open-source package. There is nothing else to buy or run.

Will there be a cloud version?

There are no plans for one. Local-first is the identity, not a phase.

How do I install MemoryDock?

Clone the GitHub repository and follow the source installation guide. The project is distributed from GitHub source.

Compatibility

Which clients work?

Anything that speaks MCP. Tested so far: Claude Code, Codex CLI, and Cursor. If your client of choice misbehaves, that's a bug — tell us.

Windows, macOS, Linux?

Windows, macOS, and Linux are supported with Node.js 22 or 24 LTS. See the Windows MCP path guidance in the installation guide.

Does it work offline?

With Ollama, fully — server, embeddings, and agents can all run without any internet connection. With a hosted provider, only the embedding calls need the network.

Misc

Is MemoryDock open source?

Yes. MemoryDock is available on GitHub under the Apache-2.0 license. Your notes remain your own Markdown files.

How do I report a bug or ask for something?

Open an issue in the GitHub repository. For vulnerabilities, follow its security policy instead of posting details publicly.
