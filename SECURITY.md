# Security policy

MemoryDock's local API is designed for one user on one computer and has no account authentication. Keep it bound to loopback. Do not expose port `40889` to a public or shared network.

If you find a vulnerability, use GitHub's **Report a vulnerability** action in the [Security tab](https://github.com/liam61-hub/memorydock/security) when it is available. Do not put exploit details or real credentials in a public issue. If private reporting is unavailable, open a public issue asking the maintainer for a private reporting channel without disclosing the details.

Security fixes are developed and tested before public disclosure. Supported versions are the current GitHub `main` branch; no separate release series is maintained yet.
